Practice room

        
New to CTFs? Work through these three in order. Each one teaches a habit you’ll use on the real board.

      

    

    

      

        
    
          
  1. Know what you’re looking for
    A flag is a string in the format flag{...}. Copy it exactly, braces included. Flags are case-sensitive.
    2. 
          
  2. Recognise encodings
    Strings ending in = with letters, digits, + and / are usually Base64. Encoding isn’t encryption: anyone can reverse it.
    3. 
          
  3. Look behind the page
    Websites carry more than you can see. Right-click and choose Inspect, or press F12, to read the HTML, comments and storage.
    4. 
          
  4. Use hints, then write-ups
    Stuck for more than 15 minutes? Open the hint. Still stuck? The How to solve page walks through every challenge.
